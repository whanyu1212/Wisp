Quickstart

Start Wisp in a repository and give it a concrete task.

Before you start

Install Wisp and configure a supported provider. See the installation and provider guides for platform details.

Open your project

cd path/to/project
wisp

The terminal interface keeps your conversation and working controls together.

Give it a bounded task

Find the code responsible for this error.
Explain the cause before changing anything.

Review what Wisp finds. You can redirect it while it works and inspect the transcript afterward.

Keep control of the work

Read the tools and safety guide before changing permission settings. The TUI guide explains steering, commands, and session history.

Learn / Chapter 1

The smallest
coding agent

Build the loop that lets a model inspect a problem and act on what it finds.

What you will build

A model/tool loop with correlated tool results and an explicit stopping rule.

The model decides; the host executes

A tool call is data until the host validates and dispatches it.

Model response → Host executes → Tool result

The next request carries the result back to the model. A response without tool calls ends this run.

Run the checkpoint

python -m examples.crafting_agents.checkpoint_01

The implementation is maintained with the runnable examples. The final page includes code directly from that source.
