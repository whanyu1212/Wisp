# Reference

Exact surfaces — flags, fields, schemas. Narrative explanation lives in the
[Guide](../guide/index.md); design rationale lives in [Architecture](../architecture/index.md).

Looking up an invocation? Start with the [CLI reference](cli.md) for commands, flags, and exit codes.
Embedding Wisp? The [Python SDK reference](sdk.md) covers supported namespaces, controller methods,
options, and typed results; the [SDK guide](../guide/sdk.md) walks through complete tasks.

For a setting that is not taking effect, check [Configuration](configuration.md) for precedence before
changing an environment variable. Read [Compatibility & versioning](compatibility.md) before upgrading
an integration or opening saved sessions with a different release. Use this section's navigation
for the complete set of contracts.

> [!WARNING]
> **Keep in sync with code**
>
> These pages describe versioned surfaces. When a command, flag, environment variable, or settings
> field changes, update the corresponding page in the same change.
