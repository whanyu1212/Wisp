# Wisp 0.16.10 release decision and checklist

## Release decision

0.16.10 is a patch on 0.16.9 focused on terminal TUI responsiveness, readability, and live status visibility: faster scrolling and typing in the experimental live browser, per-tool-family verb colors, wider prose measure and docked side panel cap, and the 2-row telemetry deck below the composer on undocked terminals.
[Browser latency](https://github.com/whanyu1212/Wisp/pull/1150) ·
[Tool verb hues](https://github.com/whanyu1212/Wisp/pull/1151) ·
[Wide layout balance](https://github.com/whanyu1212/Wisp/pull/1152) ·
[Telemetry deck](https://github.com/whanyu1212/Wisp/pull/1153)

Install matching Python, native extension, and Rust TUI versions.
[Compatibility](../../reference/compatibility.md#wisp-01610-compatibility)

## Prepublication acceptance

- [ ] Verify CI and review feedback on the preparation PR.
- [ ] Verify both native wheels, the fallback wheel, and the source distribution in the release dry run.
- [ ] Check telemetry deck rendering and fallback thresholds alongside live browser responsiveness in direct Rex and Ghostty sessions.

```bash
gh workflow run release.yml --ref release/0.16.10
```

## Publication and public-install acceptance

- [ ] Tag the accepted main commit as `v0.16.10` and verify attestation, PyPI publication, and GitHub release creation.
- [ ] Compare SHA-256 hashes for the four distributions on PyPI and GitHub.
- [ ] In fresh Python 3.11 and 3.12 environments outside the checkout, verify that both `wisp --version` and `wisp-tui --version` report 0.16.10.
- [ ] Record the publication date in the changelog and preserve its `01610--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.9` with the same extras and use its matching TUI. Existing saved sessions
open without migration.
