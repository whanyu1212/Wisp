# Wisp 0.2.2 release decision and checklist

Status: release preparation, October 19, 2026. This PR prepares the release; it does not create
`v0.2.2` or publish packages. 0.2.1 (published October 19, 2026) is the latest stable release, and
the [0.2.1 checklist](0.2.1-release.md) records the decisions 0.2.2 keeps.

## Release decision

0.2.2 is a patch release on 0.2.1. It keeps 0.2.1's platforms (native wheels for macOS arm64 and
Linux glibc 2.28+ x86_64, plus a pure wheel) and every command, event, handshake, session,
settings, and trust format. The version is `0.2.2` in both the Python and the Cargo files.

Since 0.2.1 it contains one change:

- **Thin rules between stacked tool cards, chips sized to their name, and a gap below the prompt**
  in the TUI (#761). Rendering only; no Python change.

Known flake, not a release blocker:
`test_rpc_pending_queue_is_bounded_while_prompt_is_blocked` in `tests/cli/test_rpc_mode_queue.py`
fails occasionally on CI. Re-run a failed job before treating it as a regression.

## Prepublication acceptance

- [ ] The exact PR head has terminal green CI and no actionable review threads.
- [ ] Python formatting, lint, configured mypy, full tests, and the live RPC schema check pass.
- [ ] Rust formatting, Clippy, workspace tests, build, and the Python/Rust handoff and benchmark PTY
  tests pass.
- [ ] `mdbook build book` succeeds without logged errors.

## Publication and public-install acceptance

After this preparation PR merges, publishing requires a separate `v0.2.2` tag through the existing
release workflow. Because `0.2.2` is not a prerelease, PyPI's default install moves to 0.2.2.

- [ ] The tag points to the accepted commit, and every release job succeeds, including attestation,
  PyPI publication, and the GitHub release.
- [ ] PyPI and the GitHub release have the four distributions, with matching SHA-256 hashes.
- [ ] Outside the source checkout, `uv tool install --force --python 3.12 wisp-ai` on a native
  target reports `0.2.2` from both `wisp --version` and `wisp-tui --version`.
- [ ] In a real terminal, a run of collapsed tool cards shows a thin rule between cards, and a
  blank row separates the prompt from the first card.

## Rollback

0.2.1 and 0.2.2 read each other's sessions. To go back, run
`uv tool install --force --python 3.12 "wisp-ai==0.2.1"`.
