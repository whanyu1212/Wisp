# Wisp 0.16.4 release decision and checklist

## Release decision

0.16.4 is a patch on 0.16.3 (published November 22, 2026). It fixes concurrent `bash(operation="poll")`
serialization and per-process poll wait budgets, separates `Command exited with code N` from stdout/stderr
with a newline while keeping the TUI compatible with both formats, and adds documentation plus a runtime
hint for Monty's eager generator expressions in `codemode` ([#1132](https://github.com/whanyu1212/Wisp/pull/1132)).

Python, the native extension, and the Rust TUI move together to `0.16.4`. Supported platforms,
public APIs, session formats, and live RPC payloads are unchanged. Use matching frontend and
backend versions; see [compatibility](../../reference/compatibility.md#wisp-0164-compatibility).

## Prepublication acceptance

Record CI and dry-run links in the preparation PR. This preparation does not tag or publish.

- [ ] The preparation PR head has green CI and no actionable review threads.
- [ ] Python formatting, lint, configured mypy, tests, and the live RPC schema check pass.
- [ ] Rust formatting, Clippy, workspace tests, build, and Python/Rust terminal handoff pass.
- [ ] Astro checks, tests, build, and release-route browser tests pass.
- [ ] Candidate wheels pass installed-wheel smoke tests and exact Python/TUI/native-extension
  version checks on macOS arm64 and manylinux x86_64.
- [ ] The release dry run verifies all four distributions on the accepted commit:

```bash
gh workflow run release.yml --ref release/0.16.4
```

## Publication and public-install acceptance

After the preparation PR merges, publication requires separate authorization to tag `v0.16.4`.

- [ ] The tag points to the accepted commit; attestation, PyPI publication, and GitHub release creation succeed.
- [ ] PyPI and the GitHub release contain all four distributions with matching SHA-256 hashes.
- [ ] Outside the checkout, fresh Python 3.11 and 3.12 native installs report `0.16.4` from both
  `wisp --version` and `wisp-tui --version`.
- [ ] Inside `codemode`, verify concurrent `bash(operation="poll", ...)` calls under `asyncio.gather`
  and `bash` line parsing with `splitlines()` on multi-line output.
- [ ] Date the changelog entry after publication and preserve its `0164--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.3` with the same extras and use the matching 0.16.3 TUI. No session or
settings migration is needed.
