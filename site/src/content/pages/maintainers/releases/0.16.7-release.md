# Wisp 0.16.7 release decision and checklist

## Release decision

0.16.7 is a patch on 0.16.6 (published November 23, 2026). It improves two existing Rust TUI workflows:

- **Preview and edit from Files ([#1140](https://github.com/whanyu1212/Wisp/pull/1140)):** Click to
  preview a file without editing it. Press `e` on a selected file to open it in `$VISUAL`,
  `$EDITOR`, or `vi`. Save and exit to refresh the preview and Git status without changing the
  chat draft. At narrow widths the preview stacks below the tree.
- **Context and turn growth ([#1141](https://github.com/whanyu1212/Wisp/pull/1141)):** The docked
  `Session` panel shows a segmented context gauge, per-turn sparkline, and the latest completed
  run's throughput and duration when available. `/context` shows a growth chart when there is
  enough room and uses a per-turn list on narrow layouts.

Python, the native extension, and the Rust TUI move together to `0.16.7`. The public Python SDK,
live RPC contract, saved-session format, and supported platforms are unchanged. Use matching
frontend and backend versions; see [compatibility](../../reference/compatibility.md#wisp-0167-compatibility).

## Prepublication acceptance

Record CI and dry-run links in the preparation PR. This preparation does not tag or publish.

- [ ] The preparation PR head has green CI and no actionable review threads.
- [ ] Python formatting, lint, configured mypy, tests, and the live RPC schema check pass.
- [ ] Rust formatting, Clippy, workspace tests, build, and Python/Rust terminal handoff pass.
- [ ] Astro checks, tests, build, and release-route browser tests pass.
- [ ] Candidate wheels pass installed-wheel smoke tests and exact Python/TUI/native-extension
  version checks on macOS arm64 and manylinux x86_64.
- [ ] In a real terminal, verify click-to-preview and `e` → edit → save → refreshed preview and
  Git status, with the chat draft intact. Check the docked `Session` gauge and sparkline, and
  verify both the `/context` chart and narrow list fallback.
- [ ] The release dry run verifies all four distributions on the accepted commit:

```bash
gh workflow run release.yml --ref release/0.16.7
```

## Publication and public-install acceptance

After the preparation PR merges, publication requires separate authorization to tag `v0.16.7`.

- [ ] The tag points to the accepted commit; attestation, PyPI publication, and GitHub release creation succeed.
- [ ] PyPI and the GitHub release contain all four distributions with matching SHA-256 hashes.
- [ ] Outside the checkout, fresh Python 3.11 and 3.12 native installs report `0.16.7` from both
  `wisp --version` and `wisp-tui --version`.
- [ ] Date the changelog entry after publication and preserve its `0167--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.6` with the same extras and use the matching 0.16.6 TUI. No session or
settings migration is needed.
