# Wisp 0.16.1 release decision and checklist

## Release decision

0.16.1 is a patch on 0.16.0 (published November 21, 2026). The only runtime change is
[#1117](https://github.com/whanyu1212/Wisp/pull/1117): the Browser pane now has a clickable
`[Close]` control in both docked and expanded layouts, including during page interaction.
This preparation does not create a tag or publish packages.

Python, the native extension, and the Rust TUI move together to `0.16.1`. Supported platforms,
public APIs, session formats, and live RPC payloads are unchanged; the backend and frontend
must still be the same release. See [compatibility](../../reference/compatibility.md#wisp-0161-compatibility).

## Prepublication acceptance

Record CI and dry-run links in the preparation PR; unchecked items below remain publication gates.

- [ ] The exact preparation PR head has terminal green CI and no actionable review threads.
- [ ] Python format, lint, configured mypy, full tests, and the live RPC schema check pass.
- [ ] Rust format, Clippy, workspace tests, build, and Python/Rust terminal handoff tests pass.
- [ ] Astro format/type checks, tests, build, and release-route browser checks pass.
- [ ] Candidate wheels pass on macOS arm64 and manylinux x86_64, including installed-wheel smoke
  and exact Python/TUI/native-extension version consistency.
- [ ] The release dry run succeeds on the accepted commit and verifies all four distributions.

The existing workflow's manual dispatch performs a dry run without publishing:

```bash
gh workflow run release.yml --ref release/0.16.1
```

## Publication and public-install acceptance

After this preparation PR merges, publication requires a separately authorized `v0.16.1` tag
through the existing release workflow. PyPI's default install moves to 0.16.1 after publication.

- [ ] The tag points to the accepted commit and all release jobs succeed, including attestation,
  PyPI publication, and GitHub release creation.
- [ ] PyPI and the GitHub release contain the expected four distributions and matching SHA-256 hashes.
- [ ] Outside the source checkout, fresh Python 3.11 and 3.12 native installs report `0.16.1`
  from both `wisp --version` and `wisp-tui --version`.
- [ ] In a real terminal, open the browser, interact with a page, and click `[Close]` in both
  docked and expanded layouts. Confirm that the pane closes and the composer accepts input.
- [ ] Date the changelog entry after publication and preserve its `0161--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.0` with the same extras and use the matching 0.16.0 TUI. No session
or settings migration is needed to roll back this patch.
