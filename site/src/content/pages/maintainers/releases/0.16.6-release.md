# Wisp 0.16.6 release decision and checklist

## Release decision

0.16.6 is a patch on 0.16.5 (published November 22, 2026). It makes the Rust TUI's `Files`
side panel easier to scan with branch guides, a selection rail, a filter bar with match counts,
and aligned Git line counts. Material Design icons appear where they fit and require a Nerd
Font v3 Mono terminal font to display correctly. Filenames and Git counts take priority on narrow
rows ([#1138](https://github.com/whanyu1212/Wisp/pull/1138)).

Python, the native extension, and the Rust TUI move together to `0.16.6`. The public Python SDK,
live RPC contract, saved-session format, and supported platforms are unchanged. Use matching
frontend and backend versions; see [compatibility](../../reference/compatibility.md#wisp-0166-compatibility).

## Prepublication acceptance

Record CI and dry-run links in the preparation PR. This preparation does not tag or publish.

- [ ] The preparation PR head has green CI and no actionable review threads.
- [ ] Python formatting, lint, configured mypy, tests, and the live RPC schema check pass.
- [ ] Rust formatting, Clippy, workspace tests, build, and Python/Rust terminal handoff pass.
- [ ] Astro checks, tests, build, and release-route browser tests pass.
- [ ] Candidate wheels pass installed-wheel smoke tests and exact Python/TUI/native-extension
  version checks on macOS arm64 and manylinux x86_64.
- [ ] The release dry run verifies all four distributions on the accepted commit:

```bash
gh workflow run release.yml --ref release/0.16.6
```

## Publication and public-install acceptance

After the preparation PR merges, publication requires separate authorization to tag `v0.16.6`.

- [ ] The tag points to the accepted commit; attestation, PyPI publication, and GitHub release creation succeed.
- [ ] PyPI and the GitHub release contain all four distributions with matching SHA-256 hashes.
- [ ] Outside the checkout, fresh Python 3.11 and 3.12 native installs report `0.16.6` from both
  `wisp --version` and `wisp-tui --version`.
- [ ] In the TUI, check `Files` at docked and expanded widths, including icons with a Nerd Font
  v3 Mono terminal font, filtering, `@` references, `/diff`, and split preview.
- [ ] Date the changelog entry after publication and preserve its `0166--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.5` with the same extras and use the matching 0.16.5 TUI. No session or
settings migration is needed.
