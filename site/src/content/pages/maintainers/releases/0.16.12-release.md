# Wisp 0.16.12 release decision and checklist

## Release decision

0.16.12 is a patch on 0.16.11. It adds the [`/verbosity` (`low`, `medium`, `high`) transcript toggle](https://github.com/whanyu1212/Wisp/pull/1160),
speeds up repeated session reads via [run-snapshot and tree caching](https://github.com/whanyu1212/Wisp/pull/1161), and
completes [exhaustive typed Rust live event projection](https://github.com/whanyu1212/Wisp/pull/1165)
across `wisp-tui` ([#1162](https://github.com/whanyu1212/Wisp/pull/1162)–[#1165](https://github.com/whanyu1212/Wisp/pull/1165)).

Install matching Python, native extension, and Rust TUI versions.
[Compatibility](../../reference/compatibility.md#wisp-01612-compatibility)

## Prepublication acceptance

- [ ] Verify CI and review feedback on the preparation PR.
- [ ] Verify both native wheels, the fallback wheel, and the source distribution in the release dry run.
- [ ] Smoke test `/verbosity low`, `medium`, and `high` persistence and transcript rendering in the packaged TUI, plus session resume/refresh behavior.

```bash
gh workflow run release.yml --ref chore/release-0.16.12
```

## Publication and public-install acceptance

- [ ] Tag the accepted main commit as `v0.16.12` and verify attestation, PyPI publication, and GitHub release creation.
- [ ] Compare SHA-256 hashes for the four distributions on PyPI and GitHub.
- [ ] In fresh Python 3.11 and 3.12 environments outside the checkout, verify that both `wisp --version` and `wisp-tui --version` report 0.16.12.
- [ ] Record the publication date in the changelog and preserve its `01612--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.11` with the same extras and use its matching TUI. Existing saved sessions
open without migration.
