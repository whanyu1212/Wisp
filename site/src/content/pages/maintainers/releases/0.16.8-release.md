# Wisp 0.16.8 release decision and checklist

## Release decision

0.16.8 is a patch on [0.16.7](https://github.com/whanyu1212/Wisp/releases/tag/v0.16.7), published
November 23, 2026.

- [#1145](https://github.com/whanyu1212/Wisp/pull/1145) loads the Files root and expanded folders
  independently of the shared background search index. Refresh retains the usable tree, and
  folder failures offer a local retry.
- [#1143](https://github.com/whanyu1212/Wisp/pull/1143) improves GPT-6.2 Codex prompt caching and
  keeps verification proportional to the approved edit. Eval runs can replay saved prompts and
  report model requests and tool rounds per successful result.
- [#1144](https://github.com/whanyu1212/Wisp/pull/1144) records the SWE-bench Pro V2 pilot, including
  the task sample, grading method, and results for each model and prompt.

Python, the native extension, and the Rust TUI move together to `0.16.8`. Use the matching
frontend and backend for the new discovery RPC options. Existing saved sessions open without
migration. See [compatibility](../../reference/compatibility.md#wisp-0168-compatibility).

## Prepublication acceptance

Record CI and dry-run links in the preparation PR.

- [ ] The preparation PR head has green CI and no actionable review threads.
- [ ] Python formatting, lint, configured mypy, tests, and the live RPC schema check pass.
- [ ] Rust formatting, Clippy, workspace tests, build, and Python/Rust terminal handoff pass.
- [ ] Astro checks, tests, build, and release-route browser tests pass.
- [ ] Candidate wheels pass installed-wheel smoke tests and exact Python/TUI/native-extension
  version checks on macOS arm64 and manylinux x86_64.
- [ ] Terminal handoff tests verify lazy folder expansion, project-wide search, refresh with the
  tree retained, return to the composer, and working-directory changes.
- [ ] The release dry run verifies all four distributions on the accepted commit.

```bash
gh workflow run release.yml --ref release/0.16.8
```

## Publication and public-install acceptance

After the preparation PR merges, publication requires separate authorization to tag `v0.16.8`.

- [ ] The tag points to the accepted commit. Attestation, PyPI publication, and GitHub release
  creation succeed.
- [ ] PyPI and the GitHub release contain all four distributions with matching SHA-256 hashes.
- [ ] Outside the checkout, fresh Python 3.11 and 3.12 native installs report `0.16.8` from both
  `wisp --version` and `wisp-tui --version`.
- [ ] Date the changelog entry after publication and preserve its `0168--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.7` with the same extras and use the matching 0.16.7 TUI. Existing sessions
open without migration.
