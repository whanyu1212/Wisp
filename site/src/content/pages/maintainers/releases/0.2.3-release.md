# Wisp 0.2.3 release decision and checklist

Status: release preparation, October 20, 2026. This PR prepares the release; it does not create
`v0.2.3` or publish packages. 0.2.2 (published October 19, 2026) is the latest stable release, and
the [0.2.2 checklist](0.2.2-release.md) records the decisions 0.2.3 keeps.

## Release decision

0.2.3 is a patch release on 0.2.2. It keeps 0.2.2's platforms (native wheels for macOS arm64 and
Linux glibc 2.28+ x86_64, plus a pure wheel) and every command, event, handshake, session,
settings, and trust format. The version is `0.2.3` in both the Python and the Cargo files.

Since 0.2.2 it contains two changes, both in the TUI with no Python change:

- **Grouped MCP calls and a gap after the status marker** (#763). Consecutive calls to the same
  MCP tool collapse into one row with a count; a running group shows its open call. Every card's
  marker is one column wider.
- **Paced streaming** (#764). Streamed reply text is revealed at an even pace a word at a time,
  holding unfinished Markdown spans, table rows, and fence lines until they complete. It adds two
  environment variables: `WISP_TUI_STREAM_PACING=0` turns pacing off, and
  `WISP_TUI_STREAM_TRACE=<path>` records delta arrival times.

Known flake, not a release blocker:
`test_rpc_pending_queue_is_bounded_while_prompt_is_blocked` in `tests/cli/test_rpc_mode_queue.py`
fails occasionally on CI. Re-run a failed job before treating it as a regression.

## Prepublication acceptance

- [ ] The exact PR head has terminal green CI and no actionable review threads.
- [ ] Python formatting, lint, configured mypy, full tests, and the live RPC schema check pass.
- [ ] Rust formatting, Clippy, workspace tests, build, and the Python/Rust handoff and benchmark PTY
  tests pass.
- [ ] `mdbook build book` succeeds without logged errors.

## Publication and public-install acceptance

After this preparation PR merges, publishing requires a separate `v0.2.3` tag through the existing
release workflow. Because `0.2.3` is not a prerelease, PyPI's default install moves to 0.2.3.

- [ ] The tag points to the accepted commit, and every release job succeeds, including attestation,
  PyPI publication, and the GitHub release.
- [ ] PyPI and the GitHub release have the four distributions, with matching SHA-256 hashes.
- [ ] Outside the source checkout, `uv tool install --force --python 3.12 wisp-ai` on a native
  target reports `0.2.3` from both `wisp --version` and `wisp-tui --version`.
- [ ] In a real terminal, a run of repeated MCP calls collapses to one row with a count, and a
  streamed reply appears word by word without raw `**` or table markers flashing.
- [ ] With `WISP_TUI_STREAM_PACING=0`, streamed text appears as it arrives.

## Rollback

0.2.2 and 0.2.3 read each other's sessions. To go back, run
`uv tool install --force --python 3.12 "wisp-ai==0.2.2"`.
