# Wisp 0.16.11 release decision and checklist

## Release decision

0.16.11 is a patch on 0.16.10. It adds [transcript search](https://github.com/whanyu1212/Wisp/pull/1155),
keeps [telemetry visible beside the docked panel](https://github.com/whanyu1212/Wisp/pull/1156), and
speeds up [replay of compacted sessions](https://github.com/whanyu1212/Wisp/pull/1157).
The [startup preview](https://github.com/whanyu1212/Wisp/pull/1158) makes recent history readable
before editing resumes. It is best effort and does not reduce time to the first accepted prompt.

Install matching Python, native extension, and Rust TUI versions.
[Compatibility](../../reference/compatibility.md#wisp-01611-compatibility)

## Prepublication acceptance

- [ ] Verify CI and review feedback on the preparation PR.
- [ ] Verify both native wheels, the fallback wheel, and the source distribution in the release dry run.
- [ ] Resume a long session with the packaged TUI. Verify the preview is read-only, then use `Ctrl+F` to jump to an older match after loading finishes. Check telemetry with the side panel docked.

```bash
gh workflow run release.yml --ref chore/release-0.16.11
```

## Publication and public-install acceptance

- [ ] Tag the accepted main commit as `v0.16.11` and verify attestation, PyPI publication, and GitHub release creation.
- [ ] Compare SHA-256 hashes for the four distributions on PyPI and GitHub.
- [ ] In fresh Python 3.11 and 3.12 environments outside the checkout, verify that both `wisp --version` and `wisp-tui --version` report 0.16.11.
- [ ] Record the publication date in the changelog and preserve its `01611--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.10` with the same extras and use its matching TUI. Existing saved sessions
open without migration.
