# Wisp 0.16.5 release decision and checklist

## Release decision

0.16.5 is a patch on 0.16.4 (published November 22, 2026). It adds interactive `!` shell mode and
`Alt+S` optional output sharing with the `run_shell` live RPC command
([#1134](https://github.com/whanyu1212/Wisp/pull/1134)), renames the `Work` side-panel tab to
`Session` and adds the agent-aware `Files` tab with compacted directory tree, git diff badges,
`/` filter, `@` attachment, and guarded split code preview
([#1135](https://github.com/whanyu1212/Wisp/pull/1135)), and adds the parallel turn and subagent
swimlane waterfall timeline (`f` / `t`) in the `Session` tab
([#1136](https://github.com/whanyu1212/Wisp/pull/1136)).

Python, the native extension, and the Rust TUI move together to `0.16.5`. Supported platforms,
public Python SDK APIs, and saved session formats are unchanged, while the live RPC contract adds
`run_shell` (`schemas/live-rpc/`). Use matching frontend and backend versions; see
[compatibility](../../reference/compatibility.md#wisp-0165-compatibility).

## Prepublication acceptance

Record CI and dry-run links in the preparation PR. This preparation does not tag or publish.

- [ ] The preparation PR head has green CI and no actionable review threads.
- [ ] Python formatting, lint, configured mypy, tests, and the live RPC schema check pass.
- [ ] Rust formatting, Clippy, workspace tests, build, and Python/Rust terminal handoff pass.
- [ ] Astro checks, tests, build, and release-route browser tests pass.
- [ ] Candidate wheels pass installed-wheel smoke tests and exact Python/TUI/native-extension
  version checks on macOS arm64 and manylinux x86_64.
- [ ] The release dry run verifies all four distributions on the accepted commit:

```bash
gh workflow run release.yml --ref release/0.16.5
```

## Publication and public-install acceptance

After the preparation PR merges, publication requires separate authorization to tag `v0.16.5`.

- [ ] The tag points to the accepted commit; attestation, PyPI publication, and GitHub release creation succeed.
- [ ] PyPI and the GitHub release contain all four distributions with matching SHA-256 hashes.
- [ ] Outside the checkout, fresh Python 3.11 and 3.12 native installs report `0.16.5` from both
  `wisp --version` and `wisp-tui --version`.
- [ ] In the TUI, verify `!<command>` local shell execution with `Alt+S` output attachment, the
  `Files` side-panel tab (`[` / `]`, `/` filter, `@` reference, `Enter` preview), and the `Session`
  turn waterfall (`f` / `t`).
- [ ] Date the changelog entry after publication and preserve its `0165--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.4` with the same extras and use the matching 0.16.4 TUI. No session or
settings migration is needed.
