# Wisp 0.16.3 release decision and checklist

## Release decision

0.16.3 is a patch on 0.16.2 (published November 22, 2026). It fixes recovery after an unanswered
prompt on endpoints that require alternating roles ([#1128](https://github.com/whanyu1212/Wisp/pull/1128)),
replay of anonymous Codex output items ([#1129](https://github.com/whanyu1212/Wisp/pull/1129)), and
flaky status-row spinner timing tests ([#1130](https://github.com/whanyu1212/Wisp/pull/1130)).

Python, the native extension, and the Rust TUI move together to `0.16.3`. Supported platforms,
public APIs, session formats, and live RPC payloads are unchanged. Use matching frontend and
backend versions; see [compatibility](../../reference/compatibility.md#wisp-0163-compatibility).

## Prepublication acceptance

Record CI and dry-run links in the preparation PR. This preparation does not tag or publish.

- [ ] The preparation PR head has green CI and no actionable review threads.
- [ ] Python formatting, lint, configured mypy, tests, and the live RPC schema check pass.
- [ ] Rust formatting, Clippy, workspace tests, build, and Python/Rust terminal handoff pass.
- [ ] Astro checks, tests, build, and release-route browser tests pass.
- [ ] Candidate wheels pass installed-wheel smoke tests and exact Python/TUI/native-extension
  version checks on macOS arm64 and manylinux x86_64.
- [ ] The release dry run verifies all four distributions on the accepted commit:

```bash
gh workflow run release.yml --ref release/0.16.3
```

## Publication and public-install acceptance

After the preparation PR merges, publication requires separate authorization to tag `v0.16.3`.

- [ ] The tag points to the accepted commit; attestation, PyPI publication, and GitHub release creation succeed.
- [ ] PyPI and the GitHub release contain all four distributions with matching SHA-256 hashes.
- [ ] Outside the checkout, fresh Python 3.11 and 3.12 native installs report `0.16.3` from both
  `wisp --version` and `wisp-tui --version`.
- [ ] On an endpoint that requires alternating user and assistant roles, interrupt a request before
  the first reply and send a follow-up in the same session. Verify that it completes and the two
  prompts remain separate in the saved transcript.
- [ ] Date the changelog entry after publication and preserve its `0163--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.2` with the same extras and use the matching 0.16.2 TUI. No session or
settings migration is needed.
