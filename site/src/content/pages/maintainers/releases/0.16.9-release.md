# Wisp 0.16.9 release decision and checklist

## Release decision

0.16.9 is a patch on 0.16.8. In direct Rex sessions the experimental browser tries lossless
compression of RGB or RGBA viewport pixels and sends the smaller payload. The other change
since 0.16.8 moves some routine CI checks to the nightly schedule.
[Rex rendering](https://github.com/whanyu1212/Wisp/pull/1148) ·
[CI schedule](https://github.com/whanyu1212/Wisp/pull/1147)

Install matching Python, native extension, and Rust TUI versions.
[Compatibility](../../reference/compatibility.md#wisp-0169-compatibility)

## Prepublication acceptance

- [ ] Verify CI and review feedback on the preparation PR.
- [ ] Verify both native wheels, the fallback wheel, and the source distribution in the release dry run.
- [ ] Check live browser input and frame delivery for direct Rex and Ghostty sessions.

```bash
gh workflow run release.yml --ref release/0.16.9
```

## Publication and public-install acceptance

- [ ] Tag the accepted main commit as `v0.16.9` and verify attestation, PyPI publication, and GitHub release creation.
- [ ] Compare SHA-256 hashes for the four distributions on PyPI and GitHub.
- [ ] In fresh Python 3.11 and 3.12 environments outside the checkout, verify that both `wisp --version` and `wisp-tui --version` report 0.16.9.
- [ ] Record the publication date in the changelog and preserve its `0169--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.8` with the same extras and use its matching TUI. Existing saved sessions
open without migration.
