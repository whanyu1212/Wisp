# Wisp 0.16.13 release decision and checklist

## Release decision

0.16.13 is a patch on 0.16.12. It adds prompt rewind, live terminal output for background
processes, a docked keyboard reference, and a Powerline footer. Rewind extends the existing
session tree and fork commands with optional arguments. Existing callers keep their defaults.
[Compatibility](../../reference/compatibility.md#wisp-01613-compatibility)

## Prepublication acceptance

- [ ] Verify CI and review feedback on the preparation PR.
- [ ] Run the release workflow on the preparation branch and verify both native wheels, the
  fallback wheel, and the source distribution.

```bash
gh workflow run release.yml --ref chore/release-0.16.13
```

- [ ] In a packaged TUI with a disposable session, rewind to an earlier prompt with double `Esc`
  and verify the original conversation remains available through `/resume`.
- [ ] Watch a background process in the Session panel, filter Shortcuts by a configured binding,
  and check the status line at wide and narrow widths.

## Publication and public-install acceptance

- [ ] Tag the accepted main commit as `v0.16.13` and verify attestation, PyPI publication, and GitHub release creation.
- [ ] Compare SHA-256 hashes for the four distributions on PyPI and GitHub.
- [ ] In fresh Python 3.11 and 3.12 environments on supported native platforms outside the checkout,
  verify that `wisp --version` and `wisp-tui --version` both report 0.16.13.
- [ ] Record the publication date in the changelog and preserve its `01613--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.12` with the same extras and its matching TUI. The saved-session format is unchanged.
