# Wisp 0.16.2 release decision and checklist

## Release decision

0.16.2 is a patch on 0.16.1 (published November 21, 2026) covering
[#1119](https://github.com/whanyu1212/Wisp/pull/1119) through
[#1126](https://github.com/whanyu1212/Wisp/pull/1126): action-oriented transcript tool labels
(truthful outcome verbs, quiet approval tags, built-in/discovery/codemode/browser labels, and
common MCP labels with exact `server/tool` fallback), documented tool schemas and proactive
continuation guidance, and live-browser HTML mockup preview guidance. This preparation does not
create a tag or publish packages.

Python, the native extension, and the Rust TUI move together to `0.16.2`. Supported platforms,
public APIs, session formats, and live RPC payloads are unchanged; the backend and frontend
must still be the same release. See [compatibility](../../reference/compatibility.md#wisp-0162-compatibility).

## Prepublication acceptance

Record CI and dry-run links in the preparation PR; unchecked items below remain publication gates.

- [ ] The exact preparation PR head has terminal green CI and no actionable review threads.
- [ ] Python format, lint, configured mypy, full tests, and the live RPC schema check pass.
- [ ] Rust format, Clippy, workspace tests, build, and Python/Rust terminal handoff tests pass.
- [ ] Astro format/type checks, tests, build, and release-route browser checks pass.
- [ ] Candidate wheels pass on macOS arm64 and manylinux x86_64, including installed-wheel smoke
  and exact Python/TUI/native-extension version consistency.
- [ ] The release dry run succeeds on the accepted commit and verifies all four distributions.

The existing workflow's manual dispatch performs a dry run without publishing:

```bash
gh workflow run release.yml --ref release/0.16.2
```

## Publication and public-install acceptance

After this preparation PR merges, publication requires a separately authorized `v0.16.2` tag
through the existing release workflow. PyPI's default install moves to 0.16.2 after publication.

- [ ] The tag points to the accepted commit and all release jobs succeed, including attestation,
  PyPI publication, and GitHub release creation.
- [ ] PyPI and the GitHub release contain the expected four distributions and matching SHA-256 hashes.
- [ ] Outside the source checkout, fresh Python 3.11 and 3.12 native installs report `0.16.2`
  from both `wisp --version` and `wisp-tui --version`.
- [ ] In a real terminal, verify action-oriented transcript tool labels (including common MCP
  operations and expanded card detail) and ask Wisp for a visual layout mockup to confirm it writes
  a self-contained HTML file in the scratch folder and opens it in `/browser`.
- [ ] Date the changelog entry after publication and preserve its `0162--unreleased` anchor.

## Rollback

Reinstall `wisp-ai==0.16.1` with the same extras and use the matching 0.16.1 TUI. No session
or settings migration is needed to roll back this patch.
